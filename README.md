# DRR Builder's Journey

DRR Builder's Journey is an educational block-building simulation that teaches **Disaster Risk Reduction (DRR)** through interactive gameplay.

Players solve environmental challenges by building structures such as bridges, evacuation paths, seawalls, and emergency dams to protect communities from natural hazards.

The game combines **construction puzzles, disaster education, and creative sandbox building** to help players understand how infrastructure can reduce disaster risks.

---

## 🎮 Features

- 🧱 Block-based construction gameplay
- 🌊 Disaster scenarios (floods, tsunamis, landslides, volcano hazards)
- 🛡️ Infrastructure building (dams, sandbag barriers, bridges)
- 🚨 Evacuation missions to guide villagers to safe zones
- 📚 DRR educational facts integrated into gameplay
- 🏖️ Sandbox mode for creative experimentation

---

## 🧩 Example Missions

- **Emergency Dam** – Build sandbag defenses to survive rising floodwaters  
- **Tsunami Seawall** – Construct a protective barrier and evacuate to higher ground  
- **Valley Mega Dam** – Seal cracks in a massive dam before the valley floods  

Each mission teaches a different **DRR strategy**, encouraging players to think about resilience and infrastructure planning.
